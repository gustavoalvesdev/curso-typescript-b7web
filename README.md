# Typescript
Curso de Typescript da B7Web

## Para instalar o TypeScript globalmente (Para funcionar em todos os projetos)
`npm install -g typescript`

## Verificar a versão do TypeScript
`tsc --version`

## Para compilar o arquivo
`tsc nome_do_arquivo.ts`

## Indicando a pasta onde ficará  o arquivo armazenado
`tsc src/script.ts --outDir public`

## Impedir que gere o arquivo .JS caso haja erro no TS
`tsc src/script.ts --noEmitOnError`
